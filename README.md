# Stacking-Ensemble For Binary Classification

## 📌 Description
This repository contains Python and R source codes used to build and evaluate an ensemble model for the classification of COVID-19. Ensemble learning is a machine learning technique that combines multiple models to improve overall performance.

### 🔍 Key Features:
- **Dataset:** COVID-19 symptoms data
- **Data Processing:** Cleaning, transforming, and splitting data into training and test sets.
- **Model Development:** Implementing various machine learning models such as Support Vector Machine, Decision Tree, and Logistic Regression.
- **Ensemble Learning:** Applying ensemble techniques like stacking and voting to improve predictive performance.
- **Performance Evaluation:** Metrics such as accuracy, precision, recall, and F1-score to assess model effectiveness.

## 📂 Files in This Repository
- `Classification_of_COVID_19_with_SMOTE_OverSampling.ipynb` → Jupyter Notebook implementing classification with SMOTE Oversampling.
- `stacking_ensemble.R` → R script for stacking ensemble model.
- `Covid Dataset.csv` → Dataset used for training and evaluation. [Covid-19 symptoms data](https://www.kaggle.com/datasets/hemanthhari/symptoms-and-covid-presence?rvi=1)
- `README.md` → Project documentation.
